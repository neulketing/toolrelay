# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good intent, and keep discussion about the work. Harassment of any kind is not tolerated.

To report a problem, use the repo's **Security** tab (private report) and say it is a conduct report.
Maintainers will respond and may remove comments, issues or contributors that break these rules.
